# Fake-News-Detection
A Machine Learning-based Fake News Detection System developed using Python, Scikit-Learn, TF-IDF Vectorization, and Passive Aggressive Classifier. The project analyzes news article text and predicts whether the news is Real or Fake through a user-friendly Flask web interface.
Dataset Download:
https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset
